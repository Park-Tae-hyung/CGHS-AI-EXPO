5따라 만들기 — 한 단계씩, 끝나면 ‘다 했어요’에 체크

  1. CreateAI 연결 (도구 T3)

    크롬에서 micro:bit CreateAI → 새 세션 → micro:bit 연결. 블루투스가 없는 노트북이면 USB에 꽂은 micro:bit가 무선 중계 역할을 해요.

    밴드용 micro:bit를 손목에 찰 때 로고가 위, 버튼이 손등 쪽으로 항상 같은 방향!

  2. 동작 4개 녹화

    걷기, 앉기, 넘어짐 흉내(팔을 아래로 빠르게 떨어뜨리기), 도움 요청(손 흔들기). 동작마다 팀원 3명 이상이 10번 이상 녹화해요.

  3. 학습·테스트로 헷갈리는 동작 찾기

    테스트 화면에서 박수, 머리 긁기, 가방 내려놓기를 해 보고 “넘어짐”으로 잘못 나오는 동작을 기록해요. 그 동작을 “기타 동작” 클래스로 녹화해 넣으면 오탐이 줄어요.

  4. MakeCode에서 경보 보내기

    MakeCode에서 편집으로 열어 위 블록을 넣고 밴드 micro:bit에 내려받아요.

6탐구 과정 — 부스를 만들며 직접 확인할 것

탐구 질문
“기타 동작” 클래스를 추가하면 오탐은 얼마나 줄고, 미탐은 늘어날까?
가설
헷갈리는 동작을 따로 가르치면 오탐이 줄지만 넘어짐 데이터가 적으면 미탐이 조금 늘 수 있다.
변인
독립변인: 클래스 구성(4개 / 기타 동작 추가) · 종속변인: 오탐률, 미탐률 · 통제변인: 같은 밴드 위치, 같은 시험자
실험·데이터 수집
• 같은 시험자 3명이 동작별 10회씩 시험
• 모델 2개(전/후)로 같은 시험 반복
분석
오탐률·미탐률을 모델별로 막대 비교해요.
결론 쓰는 법
“기타 동작을 추가하자 오탐 ○%→○%, 미탐은 ○%→○%. 돌봄에서는 미탐을 먼저 줄여야 한다.”

한 줄 소개
micro:bit 가속도 센서로 동작을 CreateAI에 학습시켜, 넘어짐 흉내를 내면 보호자 micro:bit에 무선 경보가 울리는 AIoT 돌봄 밴드 체험
배운 내용을 어떻게 연결했나요?
AIOT 캠프와 디지털새싹 피지컬 AI에서 배운 가속도 센서·무선 통신으로 밴드를 만들고, 데이터 마스터의 분류 개념을 CreateAI 동작 학습에 썼습니다. 바이브 코딩으로 10회 시험 결과판을 만듭니다.
방문자가 바꿔 볼 수 있는 ‘AI의 원리’
방문자가 직접 동작을 녹화해 모델을 다시 학습시키고, 보여 주지 않은 동작(박수 등)을 넘어짐으로 착각하는 오탐을 보며 학습 데이터가 AI의 판단 범위를 정한다는 원리를 체험합니다.
맞이 (30초)
“AI는 박수를 넘어짐으로 착각할까요?” 질문 후 운영자가 넘어짐 흉내로 보호자 경보를 보여 줍니다.
체험 (3~4분)
방문자가 밴드를 차고 ‘도움 요청’ 동작을 5번 녹화해 재학습한 뒤 10회 시험해 결과판에 기록합니다.
AI가 틀리는 순간 (1분)
박수·머리 긁기·가방 내려놓기로 AI가 넘어짐으로 오판하는 순간을 만들어 봅니다.
정리·진로 카드 (1분)
오탐과 미탐 중 무엇을 먼저 줄여야 할지 이야기하고 임베디드 엔지니어·돌봄 로봇 개발자 진로 카드를 받습니다.
Plan B
재학습이 어려우면 미리 학습한 모델로 테스트만, 블루투스 오류 시 USB 중계 방식으로 운영합니다.
