⑥-4 암호 해독 작전

시저 암호 편지를 암호 바퀴로 직접 풀다가, 글자 빈도 막대로 힌트를 얻고, CyberChef로 1초 만에 해독한 뒤 짧은 문장에서는 빈도 분석이 틀리는 순간과 현대 암호의 키 개수를 보는 암호 해독 작전

우리 부스의 탐구 질문글자 빈도만 알면 암호를 풀 수 있을까? 현대 암호는 왜 AI도 못 풀까?

1이 부스를 만들면

할 수 있게 되는 것
  • 시저 암호(n칸 밀기)와 나머지 연산을 연결한다
  • 글자 빈도 분석으로 밀기 값을 추정한다
  • 키의 개수가 많으면 컴퓨터로도 풀기 어려운 이유를 말한다
현장의 AI · 진로 연결

정보보안 전문가와 암호학자는 데이터를 지키는 암호를 설계하고 약점을 분석해요. 옛 암호는 빈도 분석으로 풀렸지만, 현대 암호는 키가 너무 많아 모든 경우를 시도할 수 없어요.

📒 오늘의 단어장

시저 암호
각 글자를 알파벳 순서로 n칸 밀어 바꾸는 암호.
빈도 분석
많이 나오는 글자(영어는 E)를 이용해 암호를 푸는 방법.
키 공간
가능한 키의 개수 — 시저는 25개, 현대 암호는 상상할 수 없을 만큼 많아요.

3만들기 전에 먼저 공부하기

  1. CyberChef 연습 — ROT13(Amount 값 바꾸기), Frequency distribution CyberChef (암호·인코딩 도구) ↗
  2. 나머지 연산 — Z(25)에서 3칸 밀면 (25+3) mod 26 = 2 → C
  3. 현대 암호 규모 — AES-128 키는 2의 128제곱 가지

한 줄 소개
시저 암호를 암호 바퀴로 풀다가 글자 빈도 분석과 CyberChef로 해독하고 현대 암호의 키 개수를 비교하는 암호 해독 작전
배운 내용을 어떻게 연결했나요?
인공지능 융합수업의 암호 주제 내용과 수학의 빈도·나머지 연산을 원리로 쓰고, 활동기록지 05의 CyberChef를 해독 도구로 활용합니다.
방문자가 바꿔 볼 수 있는 ‘AI의 원리’
방문자가 빈도 통계로 추천 값을 받고 짧은 문장에서 틀리는 것을 보며, 통계 기반 추론은 데이터 양에 좌우되고 경우의 수가 충분히 크면 컴퓨터도 풀 수 없다는 원리를 체험합니다.
맞이 (30초)
암호 편지 카드를 건네며 “이 비밀 편지를 풀어 볼까요?”로 시작합니다.
체험 (3~4분)
암호 바퀴로 직접 풀어 보고, 빈도 앱의 힌트와 CyberChef로 빠르게 해독합니다.
AI가 틀리는 순간 (1분)
짧은 암호문에서 빈도 분석 추천이 틀리는 순간을 확인합니다.
정리·진로 카드 (1분)
시저 25가지와 현대 암호의 경우의 수를 비교하고 정보보안 전문가·암호학자 진로 카드를 받습니다.
Plan B
인터넷 오류 시 암호 바퀴와 종이 빈도 표로 운영합니다.
