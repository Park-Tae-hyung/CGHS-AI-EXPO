T1제미나이 캔버스로 부스 앱 만들기 (바이브 코딩 8단계)

  1. 기능을 한 문장으로 정하기

    “방문자가 ○○을 넣으면 앱이 △△을 보여 준다” 한 문장으로 적어요. 두 문장이 되면 앱을 둘로 나눕니다.

    예: “방문자가 운동 전·후 맥박을 넣으면 앱이 회복 정도를 판정하고 평균 막대에 추가한다.”

    💡 팁 종이에 화면을 먼저 그리면 프롬프트가 짧고 정확해져요. 아래 그림처럼 칸만 그려도 충분해요.

  2. 제미나이에서 캔버스 열기

    Google Gemini (캔버스)에 로그인 → 입력창 아래 캔버스(Canvas) 를 켜고 프롬프트를 붙여 넣어요. 오른쪽에 코드와 미리보기가 함께 나와요.

    학교 계정·개인 계정 사용 규칙은 선생님 안내를 따르세요. 앱 안에 AI 기능을 넣는 기능(앱 안 Gemini 호출)은 만 18세 이상만 쓸 수 있으니 쓰지 않아요.

  3. 6대 요소 프롬프트로 요청하기

    [역할] [목표] [사용자] [기능] [디자인] [제약] 여섯 칸을 채워요. 제약에는 항상 “한 파일, 한국어, 외부 AI 호출 없음, 이름·연락처 입력칸 없음, 태블릿 가로 화면, 큰 글씨”를 넣어요.

  4. 데이터는 코드 안에 넣기

    문제·카드·가상 데이터는 표로 붙여 넣고 “이 데이터를 코드 안에 넣어 줘”라고 써요. 그래야 인터넷이 끊겨도 돌아가요.

    표는 스프레드시트에서 복사해 그대로 붙여 넣어도 돼요.

  5. 6점 체크리스트로 점검하기

    1. 처음 보는 친구가 설명 없이 쓸 수 있다
    2. 버튼을 아무렇게나 눌러도 멈추지 않는다
    3. 결과가 크게 보인다(2m 거리에서 읽힘)
    4. ‘처음으로’로 다음 사람이 바로 시작할 수 있다
    5. 인터넷을 끊어도 된다
    6. 개인정보를 묻지 않는다

  6. 고칠 때는 버그 틀로 하나씩

    “○○을 했더니 → △△이 되었고 → 원래는 □□이길 바란다.” 한 번에 하나만 고쳐 달라고 해야 다른 곳이 망가지지 않아요.

  7. 버전 저장과 오프라인 확인

    잘 되는 버전이 나오면 코드를 복사해 메모장에 붙여 넣고 부스이름_v1.html 로 저장(인코딩 UTF-8). 크롬으로 열어 와이파이를 끈 채 동작하는지 확인해요.

    다음 수정이 망가지면 이 파일로 돌아가요. v1, v2, v3… 로 차곡차곡.

  8. 공유가 필요하면 GitHub Pages + QR

    히어로 수업에서 배운 대로 GitHub 저장소에 index.html을 올리고 Pages를 켜면 주소가 생겨요. 그 주소로 QR을 만들어 진로 카드 뒷면에 붙여요.

  • 도구Google Gemini (캔버스)
  • 문서제미나이 캔버스 소개 (구글 코리아 블로그)
  • 영상제미나이 Canvas 완벽 가이드
  • 영상바이브 코딩 입문 — 프롬프트로 앱 만들기

T2티처블 머신으로 분류 모델 만들기 (이미지·소리·포즈)

  1. 프로젝트 고르기

    Teachable Machine (구글) → 시작하기 → 이미지 프로젝트(표준 이미지 모델), 오디오 프로젝트, 포즈 프로젝트 중 하나를 골라요.

  2. 클래스 이름 정하고 샘플 모으기

    Class 1, Class 2의 연필 아이콘을 눌러 이름을 바꿔요(예: 정상/불량). 클래스마다 30장 이상, 각도·조명·배경·사람을 바꿔 가며 찍어요.

    소리 프로젝트는 먼저 배경 소음 클래스를 20초 이상 녹음해야 다음 클래스가 열려요.

    ⚠ 주의 데이터가 한쪽으로 쏠리면(예: 밝은 곳에서만 찍음) 그게 그대로 ‘편향’이 돼요. 일부러 다양하게!

  3. 모델 학습시키기

    가운데 모델 학습시키기를 눌러요. 학습 중에는 탭을 바꾸거나 창을 닫지 마세요(학습이 멈춰요).

    고급 설정의 에포크(반복 횟수)는 처음엔 그대로 두세요.

  4. 미리보기로 시험하고 데이터 보충하기

    오른쪽 미리보기에 물건을 비춰 확률 막대를 봐요. 잘 틀리는 경우(다른 각도, 어두운 곳)를 찾아 그 상황의 샘플을 더 넣고 다시 학습해요.

    이 “틀리는 상황”이 박람회 날 AI가 틀리는 순간이 돼요. 기록해 두세요.

  5. 모델 내보내기 → 업로드 → 링크 복사

    모델 내보내기 → 업로드(공유 가능한 링크) 를 누르면 `https://teachablemachine.withgoogle.com/models/…/` 주소가 생겨요. 이 주소를 메모해 두세요.

  6. 우리 앱에서 쓰기

    T1 프롬프트의 [기능]에 다음 문장을 더해요.

    ⚠ 주의 모델 링크로 불러오는 앱은 인터넷이 필요해요. Plan B로 티처블 머신 미리보기 화면 자체를 띄워 두세요.
  • 도구Teachable Machine (구글)
  • 영상티처블 머신 이미지 사용법과 수업 사례 (열정김선생)
  • 영상티처블 머신 오디오 사용법 (열정김선생)
  • 영상티처블 머신 포즈 사용법 (열정김선생)

T3micro:bit CreateAI로 동작 인식 AI 만들기

  1. 연결하기

    크롬/엣지에서 micro:bit CreateAI → 새 세션 → 안내에 따라 micro:bit를 연결해요. 블루투스가 없는 컴퓨터는 micro:bit가 한 대 더 필요해요(무선 중계용).

    학습·테스트는 V1도 되지만, MakeCode에서 모델을 돌리려면 micro:bit V2가 필요해요.

  2. 동작별 데이터 녹화

    동작 이름을 정하고(예: 걷기·앉기·넘어짐 흉내·손 흔들기) 동작마다 10번 이상, 팀원 여러 명이 녹화해요. 손목에 차는 방향(로고 위)을 항상 같게!

  3. 학습하고 테스트하기

    학습하기(Train model) → 테스트 화면에서 동작을 해 보고 잘 틀리는 동작은 녹화를 더해요. 비슷한 동작끼리는 일부러 다르게 만드는 것도 방법이에요.

  4. MakeCode에서 편집하기

    MakeCode에서 편집(Edit in MakeCode) 을 누르면 ‘Machine Learning’ 블록 메뉴가 생긴 MakeCode가 열려요. ‘ML ○○이 시작되면’ 블록 안에 LED·소리·무선 보내기를 넣어요.

  5. 내려받기와 배터리 운영

    USB로 연결 → 다운로드 → 안내에 따라 micro:bit에 옮겨요. 모델과 코드가 함께 들어가요. 배터리 팩을 끼우면 컴퓨터 없이 동작해요.

    💡 팁 프로젝트를 저장(… → 파일로 다운로드)해 두면 다음 시간에 이어서 할 수 있어요.

T4MakeCode로 센서 값 읽고 그래프 보기

  1. 센서 연결하기

    아날로그 센서는 신호선 → P0(또는 P1·P2), +선 → 3V, −선 → GND. 악어클립보다 확장 보드가 덜 빠져요.

  2. 값을 시리얼로 보내고 그래프 보기

    Microsoft MakeCode for micro:bit 새 프로젝트 → 아래 블록을 만들고 장치 연결(USB) → 다운로드 → 데이터 보기를 누르면 실시간 그래프가 나와요. 센서가 제대로 붙었는지 제일 먼저 이걸로 확인해요.

  3. 기준값(문턱값)으로 판정하기

    AI 판정의 가장 단순한 형태는 기준값보다 크면 A, 작으면 B예요. 기준값을 바꾸면 결과가 바뀌는 걸 방문자가 직접 보게 하는 것이 많은 부스의 핵심이에요.

  4. 무선으로 두 대가 대화하기

    같은 무선 그룹 번호를 정한 두 micro:bit는 문자열·숫자를 주고받아요. 보내는 쪽(센서)과 받는 쪽(알림·화면)을 나눠요.

  5. 확장 기능 추가(네오픽셀·서보)

    블록 목록 아래 확장(Extensions) → neopixel 검색 → 추가. 서보는 기본 ‘핀’ 메뉴의 서보 쓰기 P1 각도 블록을 써요. 서보·모터는 보드 전원이 약하면 떨리니 확장 보드 전원을 써요.

  • 도구Microsoft MakeCode for micro:bit
  • 영상마이크로비트끼리 라디오 무선 통신 (러봇랩)
  • 영상마이크로비트 서보모터 제어하기 (입문편)
  • 영상서보모터·네오픽셀로 전시 작품 만들기

T5micro:bit V2 데이터 로깅으로 표(CSV) 만들기

  1. 데이터 로거 확장 추가

    MakeCode → 확장 → datalogger 추가. 열 이름(예: 상황, 밝기, 소리)을 정해요.

  2. 기록 블록 만들기

  3. MY_DATA 열어 CSV 받기

    micro:bit를 컴퓨터에 꽂으면 MICROBIT 드라이브에 MY_DATA.HTM이 생겨요. 열면 표와 그래프가 보이고 Download → CSV로 받을 수 있어요(Orange3·스프레드시트에서 사용).

  4. 상황마다 충분히 모으기

    상황 하나에 100줄 이상이 좋아요. 기록이 끝나면 로그 삭제 블록이나 새 프로그램 내려받기로 지워요.

    ⚠ 주의 MY_DATA 화면 일부 기능은 인터넷 연결 시 불러와요. 오프라인이면 표만 보여도 정상이에요.
  • 문서micro:bit 데이터 로깅 안내
  • 문서MY_DATA 파일 열기·CSV 내려받기

T6Orange3로 코딩 없이 머신러닝

  1. 설치와 첫 화면

    Orange Data Mining (오렌지3 내려받기)에서 내려받아 설치(학교 PC는 선생님께 요청). 왼쪽 위젯 목록에서 끌어다 놓고 위젯끼리 선으로 이어요.

  2. 분류(의사결정나무) 흐름

    File에서 CSV를 열고, 맞힐 열(예: 상황)을 target으로 지정해요. Test and Score에서 정확도(CA)를 확인해요.

  3. 예측(회귀) 흐름

    숫자를 예측할 때는 Linear Regression을 쓰고 Predictions로 예측값과 실제값을 비교해요. Scatter Plot으로 점과 경향을 함께 봐요.

  4. 군집(비슷한 것끼리 묶기) 흐름

    정답 열이 없을 때 k-Means로 묶고 Scatter Plot에서 무리별 색을 봐요. 무리마다 이름 붙이기(페르소나)가 사람의 몫이에요.

  • 도구Orange Data Mining (오렌지3 내려받기)
  • 영상오렌지3 기초 사용법
  • 영상오렌지3를 활용한 인공지능 기초
  • 영상엘리쌤 Orange3 데이터분석·머신러닝 재생목록

T7구글 설문·시트·Apps Script로 실시간 결과판

  1. 구조 이해하기

  2. 설문 만들기

    이름·학번을 묻지 않고 별명·선택지·숫자만 받아요. 응답 탭 → 시트에 연결.

  3. 시트 차트 띄우기

    응답 시트에서 열을 골라 삽입 → 차트. 대형 모니터에 시트를 전체 화면으로 띄우면 응답이 들어올 때마다 그래프가 바뀌어요.

  4. (심화) Apps Script 웹앱

    시트 → 확장 프로그램 → Apps Script. 바이브 코딩으로 “이 시트의 응답을 읽어 막대그래프로 보여 주는 웹앱(doGet)”을 만들고 배포 → 웹 앱. 접근 권한은 선생님과 상의해 정해요.

  • 문서Google Apps Script
  • 영상구글 시트 앱스 스크립트 기초 사용법

T8캔바와 교사 계정 생성형 AI 쓰기

  1. 연령 제한 확인하기

    음악 생성(예: Suno)은 13세 이상, 18세 미만은 보호자 동의가 필요하고, 이미지 생성 기능도 연령 제한이 있어요. 그래서 박람회에서는 선생님 계정으로 생성하고 학생은 프롬프트를 쓰고 결과를 고르고 고치는 역할을 해요.

    ⚠ 주의 실존 인물·연예인·기존 캐릭터·브랜드 로고는 프롬프트에 넣지 않아요.

  2. 생성 기록표 쓰기

  3. AI 초안 → 사람이 고르고 고친다

  • 도구Canva
  • 문서Suno 이용약관 (13세 이상, 18세 미만은 보호자 동의)
