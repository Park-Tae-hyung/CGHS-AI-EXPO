6탐구 과정 — 부스를 만들며 직접 확인할 것

탐구 질문
AI가 잘 맞히는 단어와 못 맞히는 단어는 무엇이 다를까?
가설
모양의 특징이 뚜렷하고 사람마다 비슷하게 그리는 단어일수록 잘 맞힐 것이다.
변인
독립변인: 단어의 종류(동물·사물·자연현상·장소) · 종속변인: 맞힌 비율
실험·데이터 수집
• 박람회 대시보드의 단어별 기록 모으기
• 데이터 페이지에서 그림의 다양성(모양 종류 수) 세기
분석
단어 종류별 평균 맞힘 비율과 그림 다양성 비교
결론 쓰는 법
“그림 모양이 다양한 단어일수록 맞힘 비율이 ○% 낮았다 — AI는 평균적인 그림에 강하다.”

10신청서 작성 예시 — 그대로 베끼지 말고 우리 팀만의 변형을 더해 고쳐 쓰세요

한 줄 소개
Quick, Draw!에서 20초 그림을 신경망이 맞히고, 세계 사람들의 그림 데이터와 비교해 AI가 배운 평균 그림을 찾아보는 체험
배운 내용을 어떻게 연결했나요?
캠프 머신러닝 강좌의 신경망 개념과 리터러시 강좌의 “AI가 배운 동그라미” 이야기를 설명에 쓰고, 바이브 코딩으로 맞힌 개수 대시보드를 만듭니다.
방문자가 바꿔 볼 수 있는 ‘AI의 원리’
방문자가 그림을 그리고 다른 나라 그림과 비교하며, 신경망은 많이 본 그림 방식에 맞춰 판단하므로 데이터에 적은 스타일에 약하다는 원리를 체험합니다.
맞이 (30초)
“20초 안에 그린 그림을 AI가 맞힐까요?”로 시작합니다.
체험 (3~4분)
Quick, Draw!로 6단어를 그린 뒤 맞힌 개수와 틀린 단어를 대시보드에 입력합니다.
AI가 틀리는 순간 (1분)
AI가 틀린 단어를 데이터 페이지에서 찾아 다른 나라 사람들은 어떻게 그렸는지 비교합니다.
정리·진로 카드 (1분)
“내 그림 탓일까, 데이터 탓일까?”를 이야기하고 컴퓨터 비전 연구원 진로 카드를 받습니다.
Plan B
인터넷이 끊기면 종이 그림과 팀원 AI 역할 게임으로 운영합니다.
