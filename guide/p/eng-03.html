우리 부스의 탐구 질문교실 상황(공부·휴식·수면)을 밝기·소리 데이터로 AI가 알아맞힐 수 있을까? 의사결정나무는 어떤 질문을 할까?

1이 부스를 만들면

할 수 있게 되는 것
  • 데이터 로깅으로 상황별 센서 데이터를 수집해 CSV로 만든다
  • Orange3 의사결정나무로 분류하고 정확도(Test and Score)를 확인한다
  • 나무 규칙을 MakeCode “만약” 블록으로 옮겨 실제 장치를 만든다
현장의 AI · 진로 연결

스마트 빌딩은 조도·소리·인체 감지 데이터로 공간 상태를 판단해 조명과 냉난방을 조절해요. 데이터 엔지니어는 이런 규칙을 데이터에서 찾아내고, 설명 가능한 모델(의사결정나무)을 선호하기도 해요.

5따라 만들기 — 한 단계씩, 끝나면 ‘다 했어요’에 체크

  1. 상황별 데이터 수집 (도구 T5)

    A 버튼 = 공부(형광등 켜짐·조용), B 버튼 = 휴식(대화 소리), A+B = 수면(불 끔·조용)으로 상황을 바꿔 가며 1초마다 기록해요. 상황당 100줄 이상, 시간대와 자리를 바꿔 여러 번.

  2. CSV를 Orange3에 넣기 (도구 T6)

    상황 열을 target으로 지정하고 Test and Score의 CA(정확도)를 기록해요.

  3. 나무 규칙을 램프 코드로 옮기기

  4. 나무 그림 판넬

    Tree Viewer를 캡처해 A2로 크게 출력하고, 방문자가 손가락으로 질문을 따라가게 해요. 정확도와 데이터 수도 적어요.

micro:bit 밝기·소리 데이터로 Orange3 의사결정나무를 학습시키고, 나무 규칙을 램프에 옮겨 상황에 따라 모드가 바뀌는 데이터 램프
배운 내용을 어떻게 연결했나요?
디지털새싹 데이터 마스터에서 배운 센서 데이터 수집과 Orange3 분류를 부스의 핵심으로 쓰고, 피지컬 AI의 LED 제어로 램프를 만듭니다.
방문자가 바꿔 볼 수 있는 ‘AI의 원리’
방문자가 센서를 가리거나 소리를 내며 의사결정나무의 질문 경로를 따라가 보고, 데이터에 없던 상황(손전등)에서 AI가 틀리는 것을 확인합니다.
맞이 (30초)
“지금 이 교실은 공부·휴식·수면 중 어떤 상황일까요?” 질문합니다.
체험 (3~4분)
센서를 손으로 가리거나 박수를 쳐서 상황을 바꾸고 램프 모드 변화를 본 뒤, 나무 판넬에서 질문 경로를 따라갑니다.
AI가 틀리는 순간 (1분)
스마트폰 손전등을 비추면 밤인데도 “공부”로 착각하는 순간을 보여 줍니다.
정리·진로 카드 (1분)
데이터가 규칙을 만든다는 정리와 데이터 엔지니어·스마트홈 개발자 진로 카드를 받습니다.
